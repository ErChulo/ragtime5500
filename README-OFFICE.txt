RAGTIME 5500 — OFFICE START

This package is for managed office browsers that block file:// pages.

1. Extract the ZIP to a normal local folder.
2. Double-click Start-Ragtime5500.cmd.
3. Keep the black launcher window open while using Ragtime.
4. Your browser opens http://127.0.0.1:8765/ automatically.
5. Close the launcher window when finished.

SECURITY
- 127.0.0.1 is the local workstation only.
- No internet connection is required.
- The application still blocks outbound HTTP(S), WebSocket, EventSource, and telemetry.
- The launcher serves only the bundled Ragtime HTML from this folder.

If the .cmd file is blocked by office policy, copy the exact Windows message or screenshot.
